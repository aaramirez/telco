# Cómo funciona un telco

Curso visual e interactivo sobre cómo funciona la tecnología de un operador de telecomunicaciones: redes, el modelo OSI, switching, IP, aplicaciones cliente-servidor, la red de fibra, la gestión de red (ACS, RADIUS), los sistemas OSS/BSS y la cadena de valor del telco.

Pensado para quienes trabajan en telecomunicaciones, en cualquier área, sin necesidad de saber de redes.

**Ver en línea:** https://aaramirez.github.io/telco/

Estado: la ruta completa (30 capítulos en 6 partes) está publicada; los capítulos se irán abriendo a medida que estén listos.

## Usarlo localmente

No necesita instalación ni servidor: abre `index.html` en el navegador. El avance se guarda en el `localStorage` de cada navegador.

Este repositorio contiene el sitio generado; no se edita a mano.
